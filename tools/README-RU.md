## blur

Плеер для длинных аудио — книг, подкастов и лекций.

Появился из желания удобно засыпать под размеренное повествование.

## Что внутри

- **Переход по времени** — введите время с клавиатуры и слушайте с этого места, без свайпов по длинной шкале в темноте
- **Без автовоспроизведения** — файл закончился, и тишина: случайный трек не разбудит
- **Запоминает позицию** — поставили на паузу, закрыли телефон, вернулись ровно туда же


Это мой личный плеер, здесь только то, что слушаю я. Если хотите такой же
со своим контентом — код открытый, берите :^)

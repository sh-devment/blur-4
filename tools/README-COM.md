## blur

A player for long-form audio — books, podcasts and lectures.

It grew out of wanting an easy way to fall asleep to a slow, steady narration.

## What's inside

- **Jump to a time** — type the time on the keyboard and listen from there, no swiping along a long timeline in the dark
- **No autoplay** — when the file ends, there's silence: no random track to wake you up
- **Remembers your place** — pause, lock your phone, and come back to exactly where you left off


This is my personal player, so it only has what I listen to. If you want
one like it with your own content — the code is open, take it :^)
